# Sistema de Gerenciamento de Produtos (CRUD em PHP)

Este é um sistema web desenvolvido em PHP que oferece um conjunto completo de funcionalidades para gerenciamento de produtos.

## Funcionalidades Principais

O sistema permite:

* **Autenticação de Usuários**:
    * **Login**: Acesso restrito a usuários cadastrados.
    * **Logout**: Encerramento seguro da sessão.
    * **Proteção de Rotas**: Páginas restritas são bloqueadas para usuários não logados, garantindo a segurança do acesso.

* **CRUD Completo de Produtos**:
    * **Criar (Create)**: Formulário intuitivo para cadastrar novos produtos.
    * **Ler (Read)**: Listagem organizada de produtos em formato de tabela.
    * **Atualizar (Update)**: Edição de informações de produtos existentes.
    * **Deletar (Delete)**: Remoção de produtos com confirmação para evitar exclusões acidentais.

* **Busca e Ordenação**:
    * **Filtro por Nome**: Funcionalidade de busca dinâmica para encontrar produtos rapidamente pelo nome.
    * **Ordenação Padrão**: Produtos listados do mais novo para o mais antigo por padrão.

## Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias:

* **Front-end**:
    * **HTML5**: Estrutura e conteúdo das páginas web.
    * **CSS3**: Estilização básica para uma interface limpa e funcional.

* **Back-end**:
    * **PHP**: Linguagem de programação principal para o desenvolvimento do CRUD, autenticação e controle de sessões.
    * **MySQL**: Sistema de gerenciamento de banco de dados para armazenamento persistente das informações dos produtos e usuários.

* **Servidor**:
    * **XAMPP/WAMP**: Ambiente de desenvolvimento que inclui Apache (servidor web) e MySQL (servidor de banco de dados), facilitando a execução local do sistema.
