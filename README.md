
# Sistema de gerenciamento de Produtos (CRUD em PHP)

Sistema WEB em PHP que permite:
- Autenticação de usuários (login/logout);
- CRUD completo de produtos (Cadastrar, listar, editar, excluir);
- Sessões PHP para controle de acesso;
- Busca de produtos por nome;
- Ordenação do mais novo para o mais o antigo.


## Tecnologias Utilizadas

- Front-end:
    HTML5,CSS3(estização básica).
- Back-end:
    PHP(Sessões, CRUD, Autenticação), MySQL(Banco de dados).
- Servidor: 
    XAMPP/WAMP(Apache + MySQL).
    

## Funcionalidades

    1. Autenticação de usuários
        Login: Acesso restrito a usuários cadastrados.
        Logout: Encerramento seguro da sessão.
        Proteção de rotas: Páginas restritas sem login são bloquedas.
    2. CRUD de produtos
        Criar: Formulário para cadastrar novos produtos.
        Ler: Listagem de produtos em tabela.
        Atualizar: Edição de produtos existentes.
        Deletar: Remoção com confirmação.
    3. Busca e Ordenação
        Filtro por nome (busca dinâmica).
        Ordenação padrão: Produtos mais recentes primeiro.
